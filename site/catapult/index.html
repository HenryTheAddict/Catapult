Core Design

1. Install with the DMG

Fresh installs use the signed disk image with the Applications shortcut, so new users get the normal Mac install flow.

2. Update with upsweets

In-app updates keep using the compact .upsweet package. No zips, no mystery folders, no broken paths.

3. Keep old builds working

The legacy update folder stays available while new app builds read the canonical h3nry.xyz/catapult manifest.
